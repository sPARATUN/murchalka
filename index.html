        Примечание

        Как добавить книжку

        1. 1Скачай файл книги где угодно: в Safari, Telegram, почте. Подойдут EPUB, FB2, FB2.ZIP, TXT.
        2. 2Нажми кнопку ниже — откроются «Файлы».
        3. 3Внизу выбери «Обзор», затем папку «Загрузки» (или «Недавние») и коснись книжки. Можно отметить сразу несколько.

        Из Telegram: открой файл → «Поделиться» → «Сохранить в Файлы», потом шаг 2.
